# rclone-pc-backup

Static site for the personal **rclone-pc-backup** OAuth application.

- Homepage: https://siruer.github.io/rclone-pc-backup-site/
- Privacy policy: https://siruer.github.io/rclone-pc-backup-site/privacy.html

The app is a private, single-owner rclone backup setup. It requests only the Google Drive `drive.file` scope and does not collect or share user data.
