Privacy Policy

rclone-pc-backup · Last updated: 2026-10-25

This privacy policy describes how the personal application rclone-pc-backup handles Google user data. The application is a private backup setup operated by its owner; it is not a public service and has no user accounts.

1. What data the app accesses

The app requests the following Google OAuth scope:

  • https://www.googleapis.com/auth/drive.file — view, create, modify, and delete Google Drive files that this app created or that were opened through it.

The app uses this access only to upload and manage backup files in the owner's Google Drive. It cannot browse unrelated files in the Drive library.

2. How data is used

Files are copied from the owner's computer to a dedicated folder in the owner's own Google Drive. The app does not read file contents for any other purpose, does not build profiles, and does not use data for advertising.

3. Collection and sharing

  • No data is collected by the developer.
  • No data is sold, rented, or shared with third parties.
  • No analytics, tracking pixels, or advertising SDKs are used.
  • The only external service involved is Google Drive, used to store the owner's backup files.

4. Storage and retention

Backup files remain in the owner's Google Drive until the owner deletes them. OAuth credentials are stored locally on the owner's computer in the rclone configuration. The developer does not operate a server that stores user data.

5. Security

Access uses Google's OAuth 2.0 flow. The OAuth client secret and refresh token are stored locally on the owner's machine and are not transmitted to the developer. The app follows the principle of least privilege by requesting only the drive.file scope.

6. Revoking access

The owner can revoke the app's access at any time at Google Account → Third-party connections. Revoking access stops future uploads; existing backup files remain in Drive until deleted.

7. Google API Services User Data Policy

The app's use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.

8. Contact

For privacy questions, open an issue at github.com/Siruer/rclone-pc-backup-site/issues.
